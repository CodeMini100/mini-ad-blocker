# Basic Demo

## Description
This guide provides step-by-step instructions for loading the extension and opening the demo page.

## Prerequisites
- A Chromium-based browser (e.g., Google Chrome)
- Cloned or downloaded copy of this repository

## Loading the Extension
1. Open your Chromium-based browser.
2. In the address bar, navigate to `chrome://extensions`.
3. Enable "Developer mode" if it is not already enabled.
4. Click "Load unpacked" (or similar option).
5. Select the folder containing this demo (e.g., `examples/basic_demo`).
6. Confirm the extension is successfully added to your browser.

## Opening the Demo Page
1. Open a new browser tab.
2. Navigate to the `index.html` file located in the `examples/basic_demo` folder. You can do this by:
   - Opening the file directly (e.g., by dragging and dropping the `index.html` file into a browser tab), or
   - Hosting the folder on a local web server and visiting the URL (e.g., `http://localhost:8080/examples/basic_demo/index.html`).
3. Interact with the demo page and verify extension functionality.

## Additional Notes
- No additional functions are required for this basic demo.
- Ensure you refresh or reload the extension after making any changes.
- Refer to the main project documentation for more advanced usage and troubleshooting tips.
